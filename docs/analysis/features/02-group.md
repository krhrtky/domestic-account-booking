# 機能仕様書: グループ・パートナー管理

## 概要

家計グループの作成、パートナー招待、負担割合設定を担う機能群。
2人1組のグループで家計を共有管理する。

## 機能一覧

| 機能ID | 機能名 | 実装ファイル | 状態 |
|--------|--------|-------------|------|
| GRP-001 | グループ作成 | `app/actions/group.ts:createGroup()` | 実装済み |
| GRP-002 | パートナー招待 | `app/actions/group.ts:invitePartner()` | 実装済み |

## ユースケース

### UC-GRP-001: グループ作成

**アクター**: 登録済みユーザー（未所属）

**事前条件**:
- ユーザーがログインしている
- ユーザーがどのグループにも所属していない

**フロー**:
1. ユーザーが設定ページにアクセス
2. グループ名と負担割合を入力（デフォルト: Household, 50:50）
3. 「グループを作成」ボタンをクリック
4. システムがグループを作成
5. システムがユーザーをuser_a（グループ作成者）として設定
6. グループ設定画面が表示される

**事後条件**:
- グループが作成されている
- ユーザーがグループのuser_aとして登録されている

**異常系**:
- E1: 既にグループに所属 → エラー「既にグループに所属しています」
- E2: 負担割合の合計が100%でない → エラー「負担割合の合計は100%である必要があります」

### UC-GRP-002: パートナー招待

**アクター**: グループ作成者（user_a）

**事前条件**:
- ユーザーがグループに所属している
- ユーザーがグループ作成者（user_a）である
- グループにuser_bがまだいない

**フロー**:
1. ユーザーが設定ページにアクセス
2. パートナーのメールアドレスを入力
3. 「招待リンクを作成」ボタンをクリック
4. システムが招待トークン（UUID）を生成
5. システムが招待レコードを作成（7日間有効）
6. 招待URLが表示される

**事後条件**:
- 招待レコードが作成されている
- 招待URLが発行されている（`/invite/{token}`形式）

**異常系**:
- E1: グループに未所属 → エラー「グループに所属していません」
- E2: グループ作成者でない → エラー「招待を送信できるのはグループ作成者のみです」
- E3: 既に2人いる → エラー「グループには既に2人のメンバーがいます」

### UC-GRP-003: 招待受け入れ

**アクター**: 招待されたユーザー

**事前条件**:
- ユーザーがログインしている
- 有効な招待URLにアクセスしている
- 招待が期限切れでない（7日以内）
- 招待が未使用

**フロー**:
1. ユーザーが招待URL（`/invite/{token}`）にアクセス
2. システムが招待トークンを検証
3. 「グループに参加」ボタンをクリック
4. システムがユーザーをグループのuser_bとして設定
5. システムが招待を使用済みにマーク
6. ダッシュボードにリダイレクト

**事後条件**:
- ユーザーがグループのuser_bとして登録されている
- 招待が使用済みになっている

**異常系**:
- E1: 招待が存在しない → エラー「無効な招待です」
- E2: 招待が期限切れ → エラー「招待の有効期限が切れています」
- E3: 招待が使用済み → エラー「この招待は既に使用されています」
- E4: 未ログイン → エラー「参加するにはログインしてください」

### UC-GRP-004: 負担割合変更

**アクター**: グループメンバー

**事前条件**:
- ユーザーがグループに所属している

**フロー**:
1. ユーザーが設定ページにアクセス
2. 新しい負担割合を入力（1〜99%の範囲）
3. 「更新」ボタンをクリック
4. システムが割合を更新
5. 成功メッセージが表示される

**事後条件**:
- グループの負担割合が更新されている
- 今後の精算計算に新しい割合が適用される

**異常系**:
- E1: 合計が100%でない → エラー「負担割合の合計は100%である必要があります」
- E2: 範囲外の値 → エラー「負担割合は1〜99の範囲で入力してください」

## データモデル

```typescript
interface Group {
  id: string           // UUID
  name: string         // グループ名
  ratio_a: number      // User A負担割合（1-99）
  ratio_b: number      // User B負担割合（1-99）
  user_a_id: string    // User A（グループ作成者）
  user_b_id: string | null  // User B（パートナー）
  created_at: Date
  updated_at: Date
}

interface Invitation {
  id: string           // 招待トークン（UUID）
  group_id: string     // 招待先グループ
  inviter_id: string   // 招待者ID
  invitee_email: string // 招待先メールアドレス
  used_at: Date | null // 使用日時
  expires_at: Date     // 有効期限
  created_at: Date
}
```

## ビジネスルール

| ルールID | 内容 |
|----------|------|
| BR-001 | 1ユーザーは1グループにのみ所属可能 |
| BR-002 | グループは最大2人まで |
| BR-003 | グループ作成者のみがパートナーを招待可能 |
| BR-004 | 招待は7日間有効 |
| BR-005 | 負担割合の合計は100%でなければならない |
| BR-006 | 負担割合は1%〜99%の範囲（0%や100%は不可） |
