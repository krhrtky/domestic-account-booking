# 機能仕様書: 取引・明細管理

## 概要

取り込んだ取引データの表示、分類変更、支払元変更、削除を行う機能群。
精算計算の基礎データを管理する。

## ユースケース

### UC-TXN-001: 取引一覧表示

**アクター**: グループメンバー

**事前条件**:
- ユーザーがログインしている
- ユーザーがグループに所属している

**フロー**:
1. ユーザーが取引ページ（`/dashboard/transactions`）にアクセス
2. システムが当月の取引を取得
3. 取引一覧がテーブル形式で表示される

**表示項目**:
- 日付（YYYY/MM/DD形式）
- 摘要（説明文）
- 金額（¥カンマ区切り形式）
- 支払元（UserA名/UserB名/共通）
- 支出タイプ（家計/個人）
- 操作ボタン（削除）

**事後条件**:
- 取引一覧が表示されている

### UC-TXN-002: 取引のフィルタリング

**アクター**: グループメンバー

**事前条件**:
- 取引一覧ページが表示されている

**フロー**:
1. ユーザーがフィルタ条件を選択
   - 月（YYYY-MM形式）
   - 支出タイプ（Household/Personal/すべて）
   - 支払元（UserA/UserB/Common/すべて）
2. システムが条件に合致する取引を取得
3. 一覧が更新される

**事後条件**:
- フィルタ条件に合致する取引のみが表示されている

### UC-TXN-003: 支出タイプ変更（Household ↔ Personal）

**アクター**: グループメンバー

**事前条件**:
- 取引一覧が表示されている

**フロー**:
1. ユーザーが対象取引の支出タイプトグルをクリック
2. システムが支出タイプを更新
3. トグルが即座に反映される
4. 精算データのキャッシュが無効化される

**事後条件**:
- 取引の支出タイプが変更されている
- 精算計算に反映される準備ができている

**ビジネスルール**:
- `Household`（家計）: 精算計算に含まれる
- `Personal`（個人）: 精算計算から除外される

### UC-TXN-004: 支払元変更

**アクター**: グループメンバー

**事前条件**:
- 取引一覧が表示されている

**フロー**:
1. ユーザーが対象取引の支払元ドロップダウンを変更
2. システムが支払元を更新
3. 表示が即座に反映される

**事後条件**:
- 取引の支払元が変更されている

**選択肢**:
- User A（実名で表示）
- User B（実名で表示）
- Common（共通口座）

### UC-TXN-005: 取引削除

**アクター**: グループメンバー

**事前条件**:
- 取引一覧が表示されている

**フロー**:
1. ユーザーが対象取引の削除ボタンをクリック
2. 確認ダイアログが表示される（※実装確認要）
3. ユーザーが確認
4. システムが取引を削除
5. 一覧から取引が消える

**事後条件**:
- 取引がデータベースから削除されている

### UC-TXN-006: ページネーション

**アクター**: グループメンバー

**事前条件**:
- 取引数がページサイズを超えている

**フロー**:
1. ページネーションコントロールが表示される
2. ユーザーがページ番号または次へ/前へをクリック
3. システムが該当ページの取引を取得
4. 一覧が更新される

**デフォルト設定**:
- 1ページあたり25件
- ページサイズ変更可能（10/25/50）

## データモデル

```typescript
interface Transaction {
  id: string                    // UUID
  group_id: string              // 所属グループ
  user_id: string               // アップロードしたユーザー
  date: string                  // 取引日（YYYY-MM-DD）
  amount: number                // 金額
  description: string           // 摘要
  payer_type: 'UserA' | 'UserB' | 'Common'  // 支払元タイプ
  payer_user_id: string | null  // 支払者ユーザーID（個人指定時）
  expense_type: 'Household' | 'Personal'    // 支出タイプ
  source_file_name: string      // 元ファイル名
  created_at: Date
  updated_at: Date
}
```

## ビジネスルール

| ルールID | 内容 | 参照 |
|----------|------|------|
| L-BR-002 | UserA/UserB: 精算計算に含まれる | 支払元ルール |
| L-BR-002 | Common: 精算計算から除外 | 支払元ルール |
| L-BR-003 | Household: 精算計算に含まれる | 支出タイプルール |
| L-BR-003 | Personal: 精算計算から除外 | 支出タイプルール |
